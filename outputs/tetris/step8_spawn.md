# step8_spawn.c · 新方块生成（Spawn 机制）

## 文件职责
固化之后从顶部中央生成下一块，游戏从"单块演示"变成"一局"。

## 主要函数
| 函数 | 职责 |
|---|---|
| `spawn(gx, gy)` | 把方块坐标复位到顶部中央，`can_place` 检查出生点；被占返回 0（游戏结束） |
| `lock_piece / can_place / paint / draw_field` | 与 Step 7 相同 |

## 关键逻辑与数据流
```
触底 ─> lock_piece() 固化并重画 ─> spawn()
        ├─ 出生点可用 ─> paint(x, y, 0) 画出新一格
        └─ 出生点被占 ─> game_over = 1，主循环退出
```

## 修复记录（2026-10-22）
**问题**：新方块生成前画面会闪烁——旧方块先消失、固化区被抹出空洞，之后新方块才出现。
**根因**：旧版 `spawn()` 里有一句 `paint(旧位置, 擦除)`。它执行在 `lock_piece()` 的 `draw_field()` **之后**，把刚画好的固化格子又擦掉了。
**修复**：删除该擦除调用。固化后旧位置由 `draw_field()` 覆盖，`spawn()` 只负责复位坐标，方块直接生成、无中间状态。

## 与其他文件的依赖关系
- 上游：Step 6（board / lock）、Step 7（can_place 撞堆）。
- 下游：Step 9 在固化后追加消行，主循环结构沿用本文件。

## 注意事项
- 主循环由 `for(;;)` 改为 `while (!game_over)`，退出路径有两个：按 q / Esc，或出生点被堵死。
