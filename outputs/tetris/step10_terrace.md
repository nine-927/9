# step10_terrace.c · 最终 terrace 场景

## 文件职责
不新增游戏机制，做场景收尾：开场标题横幅、右侧信息面板、游戏结束结算牌、重开与退出，形成完整闭环。

## 主要函数
| 函数 | 职责 |
|---|---|
| `draw_title()` | 场地右上方打出 TERRACE 标题 |
| `draw_field()` | 场地 + 分数/消行面板一次画全（场地整体下移 1 行给标题让位） |
| `new_game()` | 清 board、清分数、重画全部、顶部生成第一块、重置计时 |
| `game_over_screen()` | 场地中央结算牌（分数/消行/r 重开/q 退出），返回用户选择 |
| `main` | 外层 `while (running)` 管理整个程序，内层 `while (!game_over)` 管理单局 |

## 关键逻辑与数据流
```
程序启动 ─> new_game() ─> 单局循环(下落/移动/固化/消行)
                              └─ 出生点被堵 ─> game_over_screen()
                                                ├─ r ─> new_game() 重开
                                                └─ q ─> 结束程序
```
