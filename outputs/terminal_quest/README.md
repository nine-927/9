# 《秘境三关》Terminal Quest v1.1（3D 版）

纯 C99/C11 编写的终端"闯关"文字游戏，不依赖任何第三方图形库，
只使用标准库 + ANSI 终端控制码（Windows 下通过 Win32 API 开启
虚拟终端以支持颜色，`windows.h` 为系统自带头文件）。

第 3 关使用**光线投射 (Raycasting)** 算法，在纯字符终端里渲染出
Wolfenstein 3D 风格的第一人称伪 3D 画面：墙面按距离/朝向分档着色，
出口与陷阱作为 sprite 立在场景中，并被 z-buffer 正确遮挡。

## 文件结构

```
terminal_quest/
├── game.c      # 全部源码（单文件，约 1000 行，含中文注释）

└── README.md   # 本说明
```

## 游戏设计

- 玩家状态：生命值 HP（上限 100）、分数、当前关卡进度。
- 每关胜利自动进入下一关，关卡之间在篝火休息回复 25 HP。
- 任意关卡失败可选择：**重试本关**（HP 恢复满）或**返回主菜单**。
- 三关全部通关后进入结算界面，按分数给出星级评价。

## 关卡设计

| 关卡 | 名称 | 玩法 | 失败条件 | 得分 |
|------|------|------|----------|------|
| 1 | 守门人的谜题 | 猜 1~100 的神秘数字，共 7 次机会，每猜错扣 10 HP | HP 归零或机会耗尽 | 100 |
| 2 | 石殿的守卫 | 回合制战斗：攻击 / 重击(50%暴击50%落空) / 防御(减伤一半) / 喝药水(2瓶，各回18HP) | HP 归零 | 150 |
| 3 | 3D 迷宫逃脱 | **第一人称视角**，W 前进 / S 后退 / A 左转 / D 右转，撞墙可贴墙滑动；绿色门框是出口，红色方块是陷阱 | HP 归零或 60 步耗尽 | 200（全程不踩陷阱额外 +50） |

### 第 3 关 3D 渲染原理（简述）

1. 视口是 76×22 的字符网格，屏幕每一列发射一条射线；
2. 用 DDA 算法沿网格步进，求出射线与墙壁的交点距离（垂直距离，避免鱼眼畸变）；
3. 由距离决定该列墙面的高度，并由距离/墙面朝向挑选字符（`@ # % = -`，越远越虚）；
4. 出口 `E`、陷阱 `*` 用标准的 sprite 投影公式绘制，配合每列 z-buffer 做遮挡；
5. 顶部小地图（M 键切换）显示 9×9 迷宫全貌与朝向箭头。

## 编译与运行

### Linux / macOS

```sh
make            # 或: cc -std=c99 -Wall -Wextra -O2 -o game game.c -lm
./game
```

> 注意：3D 渲染用到 `math.h`，Linux 下需显式加 `-lm`（Makefile 已处理）。

### Windows (MinGW-w64 / MSYS2)

```sh
gcc -std=c99 -Wall -Wextra -O2 -o game.exe game.c
game.exe
```

### Windows (MSVC，开发者命令提示符)

```bat
cl /nologo /W4 /std:c11 /utf-8 game.c /Fe:game.exe
game.exe
```

## 操作说明

- **主菜单 / 第 1 关 / 第 2 关**：输入数字选项，按回车确认；非法输入会提示且不扣机会。
- **第 3 关**输入方式自适应终端类型：
  - **交互式控制台**（cmd / PowerShell / Windows Terminal / Linux & macOS 原生终端）：
    单键即时生效，无需回车——`W` 前进、`S` 后退、`A` 左转、`D` 右转、`M` 切换小地图；
    Windows 下方向键 ↑↓←→ 等效于 W/S/A/D。
  - **行缓冲终端**（例如在 Git Bash / mintty 中运行原生 exe，stdin 是管道）：
    按键需等回车才会送达，游戏会自动改为**按行读取指令**——一行可以输入多个
    指令，如输入 `wwwww` 表示连续前进 5 步、`wwddww` 表示前进→右转→前进，
    回车后依次执行（每步都会刷新一次画面）。空行仅刷新画面。
  - 程序启动时会自动检测并显示当前使用的是哪种输入模式。
- 建议终端窗口至少 **80 列 × 40 行**，否则 3D 视口或状态栏会被折行；
  空间紧张时按 `M` 关闭小地图。

## 各平台注意事项

- **Linux / macOS**：原生支持 ANSI，无需任何设置；第 3 关用 `termios` 临时关闭
  行缓冲实现单键输入，退出时会自动恢复终端设置。
- **Windows 10/11**：
  - 程序启动时会**自动**把控制台代码页切换为 UTF-8（`SetConsoleOutputCP(65001)`）并
    开启 ANSI 颜色支持，正常情况下无需任何手动设置，直接运行即可显示中文和颜色。
  - 第 3 关交互模式下用 `_getch()` 读取单键（无回显）；检测到 stdin 不是
    控制台（管道/重定向/MSYS pty）时自动切换为按行读取指令，方便
    Git Bash 使用和脚本化测试。
  - 建议使用 **Windows Terminal**（颜色和字符画显示效果最佳），并把窗口调大。
  - 若仍出现乱码，多半是控制台字体问题：请确保使用 TrueType 字体（如"新宋体"、
    Consolas、"Cascadia Mono"），不要使用点阵字体（Raster Fonts）。
  - 字符画在非等宽字体下会错位，请务必使用等宽字体。
- **Windows 7/8（老版 conhost）**：不支持 ANSI 转义码，屏幕上可能出现
  `←[2J` 之类的转义字符残留，游戏功能不受影响，但强烈建议升级终端或
  改用 Windows 10+。
- **macOS**：Terminal.app / iTerm2 均可直接运行。
